# Digital Letter 💌

A responsive, single-page digital love letter built for a girlfriend to open from a QR code (paired with a real bouquet + handwritten letter). Designed mobile-first for iPhone.

**Flow:**
1. She taps an animated envelope to open the letter.
2. A stylish, non-square photo carousel of the two of them plays.
3. A short love message fades in line by line.
4. An illustration of the couple appears with a gentle floating animation.
5. A countdown ticks down to the next time they'll kiss.
6. A button reveals random love messages on tap.

Plain HTML/CSS/JS, no build step, hosted on GitHub Pages.

🔗 Live site: https://thainanst.github.io/digitalLetter/
